03 · Logo

Lockup de marca

El wordmark es la expresión principal para producto. En la interfaz se usa como texto vivo (no imagen), en dos densidades. El isotipo del sol se reserva para espacios muy reducidos (avatar, favicon) y no se recrea aquí como vector — usar el archivo oficial del brandbook cuando esté disponible.

04 · Botones

Acciones

El coquelicot se reserva para la acción principal de la pantalla (postularse, pagar, confirmar). El verde se usa para acciones secundarias de marca; el contorno y el texto para acciones terciarias.
